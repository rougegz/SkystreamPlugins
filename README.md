# Free Drama Sources

Curated list of apps and websites for watching microdramas / short dramas
(short-form vertical series) **free** — ad-supported, no coins, no subscription
required. Verified August 2026.

> Note: "free" status changes often in this category. Apps pivot to coins,
> mirror sites change domains. Re-check before relying on any single source.

## Community methods (most reliable free routes)

1. **Dailymotion** — search the exact drama title; full uploads are widely
   available (most-repeated advice across Reddit/Quora).
2. **YouTube / TikTok** — full episodes reposted by fan accounts.
3. **Telegram** — `@ShortDramasVideo`, `@chineseminiseries01`, `@duanjupan`.
4. **Legit free tiers** — DramaBox & MoboReels unlock 15–20 episodes/day via
   ads/check-ins; iQIYI has a free "Micro-Drama Theater".

## Safety

- Paid apps cost ~$25–42 per full series; weekly auto-renew subs $17–20/week.
  Turn off autoplay or coin walls drain invisibly.
- MOD APKs / "free coin hacks" are malware — highest-risk downloads in this
  niche.
- Mirror sites: use an adblocker, don't register with real credentials, don't
  install pushed apps.
